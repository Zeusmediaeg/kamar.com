رفع الموقع على GitHub Pages:
1) ارفع كل محتويات الفولدر (index.html + portfolio.pdf + فولدر assets) في ريبو جديد.
2) Settings > Pages > Branch: main / root > Save.
3) لوحة التحكم: رابط الموقع/#admin  (zeus / 123456789) - غيّر الباسورد فورًا من "الحساب والنشر".
4) بعد أي تعديل من الداشبورد: "الحساب والنشر" > تصدير data.json > ارفعه جنب index.html عشان التعديلات تظهر لكل الزوار.
5) زر تحميل البورتفوليو بيحمّل portfolio.pdf. بعد تعديل البورتفوليو: افتح #portfolio > "طباعة / حفظ نسخة محدّثة" > Save as PDF > سمّيه portfolio.pdf وارفعه مكان القديم.
6) لينكات السوشيال (فيسبوك/انستجرام/تيك توك/X/سناب): من الداشبورد > عام والتواصل. لحد ما تتحط بتظهر باهتة في الفقاعة.
